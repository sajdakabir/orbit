# Orbit

Marketing website for **Orbit** — an AI-powered voice companion that turns your speech into perfect text, anywhere on your computer.

## Tech Stack

- **Next.js 16** with App Router
- **React 19**
- **Tailwind CSS 4**
- **Framer Motion** for animations
- **TypeScript**

## Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```

## Project Structure

```
src/
├── app/          # Next.js app router (layout, page, globals)
├── components/   # UI components (hero, navbar, footer, etc.)
public/
├── icon/         # App icons (integrations, dock)
├── screenshots/  # Product screenshots for spaces showcase
```
